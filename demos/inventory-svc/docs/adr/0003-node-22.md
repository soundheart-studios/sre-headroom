## Context
Node 20 leaves maintenance in 2026.

## Decision
Services run TypeScript on Node 22 LTS with strict mode.

## Rules
- `engines.node` is `>=22 <23`; CI uses `actions/setup-node` with `node-version: 22`.
- `tsconfig.json` has `"strict": true`.
- HTTP handlers validate input with zod.

## Consequences
Some older libraries need upgrades.

## Exceptions
None.
